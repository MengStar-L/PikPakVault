# RSS 订阅

在「RSS 订阅」添加订阅地址，将它绑定到资源库中的一个目录。每次检查只为新资源创建保存任务，结果会出现在该目录和「传输任务」中。

## 添加订阅

1. 在资源库中准备目标文件夹，打开侧栏「RSS 订阅」→「添加订阅」。
2. 填写名称和完整 RSS / Atom 地址，选择保存目录。点击文件夹即选定，无需额外确认。
3. 选择检查间隔，默认 30 分钟，范围 5 分钟至 7 天。
4. 默认只保存首次检查之后新增的条目。如需保存当前订阅中的资源，开启「同时保存订阅中现有的资源」。
5. 保存后等待自动检查，或点击「立即检查」。需要已连接且验证通过的活动 PikPak 账号。

例如 [Animes Garden 搜索订阅](https://api.animes.garden/feed.xml?search=%E5%B0%BC%E5%8F%A4%E5%96%B5%E5%96%B5) 在 enclosure 中提供磁链。本程序直接读取资源链接，不把详情页当成下载文件。

## 支持的资源

- RSS 2.0、Atom、RSS 1.0/RDF；支持 enclosure、Atom 附件、命名空间磁链以及描述中的磁链/分享链接。
- 磁链优先于同条目中的其他下载链接，按种子身份去重；同一磁链更换显示名称或 tracker 不会重复保存。
- PikPak 分享沿用现有转存流程；支持链接查询参数中携带的 pass_code / pwd / password 提取码。
- HTTP(S) 附件提交到 PikPak URL 离线接口。需要网站登录、额外 Cookie、地区限制或已过期的附件可能无法保存；具体失败原因会保留在原任务中。可在文件详情补充新的附件恢复来源。
- 普通文章链接、无法识别的资源会显示为已跳过，不抓取详情网页。一个条目提供多个候选链接时，选择一个最优支持来源，不重复保存不同表示形式。

## 去重、暂停和路径

订阅条目及资源身份与本地文件位置分开保存。移动、重命名、切号、重启、任务失败不会使旧条目再次变成“新资源”。失败时继续原任务；已完成任务不会因重新检查订阅而复制到新账号，跨账号恢复请使用恢复中心。

修改保存目录只影响之后发现的条目，已有任务和文件保留原目标。删除或移入回收站的目标目录会阻止新任务登记并显示原因；还原目录或选择新目录后再次检查即可。

暂停订阅停止自动检查并取消尚未提交结果的订阅扫描，保留已创建的保存任务。暂停期间仍可手动检查。移除订阅删除规则及其检查记录，保留资源、来源和已有任务；重新新建订阅视作新规则。

网络中断、XML 不完整、响应超限时，不提交部分条目，也不推进初次检查基线。服务支持条件请求以减少重复读取；单次最多 8 MiB / 2000 条目。

## 备份与认证

订阅 URL 可能包含访问令牌，因此在数据库中加密保存，不写入操作日志。完整备份包含订阅配置和去重记录；导入时重新加密，核对数据并恢复后台调度后继续检查。旧版本备份仍可导入，旧备份中没有的 RSS 规则会被清空。

v0.3.7 将数据库升级到 schema 3。升级由 systemd 更新服务备份后执行，保留原账号、资源、任务和缓存。
