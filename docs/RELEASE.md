修复切换账号后，保存位置已有同名文件夹就停在「需要处理」的问题。

- 新账号尚未绑定专用目录时，接纳保存路径下唯一的同名文件夹，并自动安排「核对已转移的全部文件」。
- 按完整路径、类型、大小和已保存的哈希核对，已有且完整的文件直接可用，不再重复恢复；缺失、冲突和未完成文件逐项标记。
- 全量扫描完成前，保存任务等待核对；网络或分页中断、扫描期间文件变化、切号均不提交部分绑定，重启后可继续扫描。
- 旧版因同名专用目录进入「需要处理」的任务会自动重新排队。多个同名根目录、非文件夹目标或已有根目录迁移冲突仍需核对，不覆盖云端内容。
- 保持数据库 schema 4，保留来源、收藏、播放记录、旧账号映射、传输任务及可续传缓存。
