修复 TelDrive 首次上传资源被误判为待恢复，以及由此可能创建重复上传的问题。

- 上传前预登记的文件和目录保留传输状态，不再进入恢复列表或侧栏恢复计数。暂停、失败和等待处理的任务保留会话，可继续或重试原任务；取消后允许另行恢复。
- 恢复预览、任务创建和执行统一核对当前账号已有任务，覆盖整目录展开、旧版遗留恢复任务、进程重启、切换账号与并发提交。
- TelDrive 再次扫描会跳过已由恢复任务接管的资源；取消任务后也不能重新启动旧任务与新任务重复上传。
- 恢复预览解释被跳过的项目；读取 TelDrive 文件计算指纹失败时显示已读取字节数和处理方式。
- 新增首次上传、失败/暂停/取消、真实缺失、跨账号、目录恢复和并发回归，以及使用真实后端的浏览器测试。17 项浏览器测试覆盖桌面、平板和手机。

无需迁移数据，沿用 schema 2。原账号、监控、上传会话和任务继续保留。已有实例可在设置中检查更新，确认后下载、备份与重启；systemd 升级失败可自动回滚。
