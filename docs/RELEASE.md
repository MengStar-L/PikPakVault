修复账号任务已报错但账号管理仍显示“可用”的问题。登录失效、账号被冻结、需要安全验证和空间不足会同步到账号、任务及全局提示。

- 识别 HTTP 400 user_blocked 等明确账号错误，不再仅处理 401；只有自动刷新失败后的最终错误才影响状态。
- 增加持续的账号异常提示、中文原因和“重新检查”入口，显示上次读取的容量；检查任务去重，刷新或 SSE 重连后也能获取最新状态。
- 异常账号暂停相关队列与自动调度；空间不足仍允许检查、整理和清理，保留全部来源、远端 ID、上传会话及任务进度。验证恢复后手动继续原任务。
- 账号凭据更新同时核对身份和容量；旧请求的迟到结果不会覆盖新凭据，切换账号后错误仍归属原账号。
- 同步媒体请求和离线任务内的明确账号错误也会更新状态；分享无权限、单文件失效与对象存储上传票据过期不误判为账号冻结。
- 错误信息隐藏凭据和提取码。数据库结构保持 schema 4，无需迁移。
