分享转存现在明确指定保存目录，修复文件落到 `Pack From Shared`、已保存的任务却无法完成，以及点击重试缺少反馈的问题。

- 补齐 `specify_parent_id`，分享资源直接存入选择的目录；核对返回位置，位置不符时暂停，不自动使用默认目录中转。
- 读取 `restore_task_id` 和来源到副本的 `trace_file_ids` 映射，按任务 ID 查询进度；不把响应中的目录 ID 当成转存文件。
- 响应缺少结果 ID 时，重试按原目录快照及完整来源清单核对文件大小和哈希，继续原任务；分页中断、重复候选、冲突和未完成文件均不会被错误登记。
- 文件卡片、传输列表与任务详情提供重试反馈、重复点击保护和进度轮询，SSE 断线时仍能看到结果；账号未就绪时提示先完成验证。
- 保留旧任务的已提交状态与远端 ID，支持核对后关联旧结果，无需再次转存。

数据库沿用 schema 2。升级保留账号认证、目录、来源、任务、专用 aria2 和下载缓存。

验证：接口请求与响应契约测试、分享直接保存和异常位置回归、旧任务重试、来源清单完整性检查，以及桌面和手机浏览器重试流程。完整测试结果以本版本 CI 为准。
