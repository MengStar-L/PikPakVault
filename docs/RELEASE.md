新增 TelDrive 文件夹同步：在侧栏配置站点与 access_token，选择来源及资源库目标，手动同步或开启定时检查。默认仅手动。

- 保留子目录与空目录，按源文件 ID 去重；同名冲突与内容变化提示处理，不传播源端删除。
- 文件经服务器计算 GCID，再使用 PikPak 文件上传接口保存到最终目录；不缓存整份文件。
- 分片上传状态持久化，响应丢失先检查文件和远端分片。切号暂停旧任务；新扫描上传至当前账号。
- 本地重命名、移动、收藏与播放进度在恢复和切号后继续保留。
- 完整备份包含 TelDrive 认证、监控与上传会话；支持旧版备份导入。数据库升级至 schema 2，降级需使用升级前数据备份。
- 全量 Go 测试、vet、16 项浏览器回归测试通过。新增 TelDrive 与 PikPak 上传链路使用模拟上游验证，真实实例需配置后联调。

进入「TelDrive 同步 → 添加监控」开始配置。未命中秒传时通常需要约两份文件大小的下行流量和一份上行流量，重试另计。详情见 docs/TELDRIVE.md。

Linux systemd 默认安装路径 /opt/pikpakvalue，端口 5675。已有实例可在设置中检查更新，确认后校验、备份与重启；升级失败可自动回滚。
