修复播放后缺少“已播放”标记的问题。内置音视频实际开始播放，或成功获取地址并发起 PotPlayer 播放请求后，文件列表、网格和详情会立即显示并保存播放记录。

- 仅打开预览、下载文件、获取地址失败或取消尚未完成的播放器请求，不会误标为已播放。
- 保存记录失败时提供重试，不中断当前播放；刷新页面、移动、重命名、恢复及切换云端账号后保留记录。
- 播放记录随完整数据备份导出和导入；升级至数据库 schema 4 时，为旧版已有有效播放进度的文件补齐记录。
- 保留独立的资源保存状态、收藏和续播进度，适配桌面及手机的长文件名列表和网格。

PotPlayer 标记表示已发起播放请求，不表示已看完；浏览器无法获知外部播放器是否实际开始播放。旧版没有记录的 PotPlayer 播放无法自动追补。

验证覆盖网页真实媒体播放、PotPlayer 菜单调用、失败及取消、记录重试、页面刷新、桌面/手机布局、数据库迁移及备份兼容。测试使用模拟上游，不删除真实账号文件。
