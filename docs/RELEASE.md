添加资源的路径选择器改为「进入即选定」，点击文件夹后直接以该目录为保存位置，无需再点“选择当前文件夹”。

- 保存位置展示完整路径，支持面包屑跳转、返回上级、收起后保留选择。
- 优化展开与收起、进入与返回的方向动画及点击反馈；支持键盘操作和减少动态效果。
- 增加稳定的加载、空目录和错误重试状态；快速切换时迟到的响应不会改变选中目录，退出动画中的目录不可误点击。
- 修复目录按钮误提交资源表单的问题；文件夹独立分页，不再被普通文件占用页数。
- 文件移动和 TelDrive 资源库目标使用相同的单击选择逻辑。

无需数据库迁移，账号认证、资源、来源、任务和下载缓存均保留。

验证包括深层及长路径、桌面/平板/手机、键盘选择、慢请求与失败重试、分页，以及实际提交的目标目录。
