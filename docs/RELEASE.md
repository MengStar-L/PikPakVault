新增独立「RSS 订阅」页面，每条订阅绑定一个资源库目录，自动将新资源保存到当前 PikPak 账号。

- 支持 RSS / Atom、Animes Garden 等订阅中的磁链、PikPak 分享和下载附件。
- 默认每 30 分钟检查，可暂停、手动检查、调整间隔和目标；首次仅记录已有条目，也可选择保存现有资源。
- 显示逐条保存结果和原传输任务，失败可重试。去重记录不随文件移动、重命名、重启或账号切换而丢失。
- 完整解析后事务登记条目、来源和任务；网络失败、暂停、移除规则、目标删除和执行中切号不会提交过期结果。
- RSS 地址加密保存；完整导出/导入包含订阅和去重记录，兼容旧备份。数据库升级到 schema 3。

验证覆盖真实 Animes Garden 订阅的只读解析、模拟上游导入与响应丢失、去重和任务恢复、备份迁移，以及桌面/平板/手机的订阅管理和状态刷新。测试不向真实 PikPak 账号创建资源。
