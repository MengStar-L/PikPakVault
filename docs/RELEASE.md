保存资源时，可直接在路径选择器内新建、重命名和删除文件夹，无需返回资源库再操作。直接保存、RSS、TelDrive 和移动窗口共用此交互。

- 移除重复展示当前文件夹名称的大横条，改为紧凑的顶部路径、返回上级和新建按钮。
- 新建文件夹后自动进入并选定；当前目录和每个子目录均有操作菜单，删除前说明内容将一起移入回收站，删除当前目录后返回上级。
- 文件夹管理期间阻止提交外层保存表单；失败保留输入，阻止重复请求，离场动画中的控件不再接受操作。
- 更新分页与路径缓存，避免删除最后一页内容后停留在空页；适配手机、长路径和减少动画设置。
- 后端在新建事务内验证完整父目录路径，禁止在回收站或失效的目录树下创建文件夹。

验证包含真实测试后端的目录操作、失败/延迟请求、分页与表单隔离、桌面/平板/手机显示，以及原有资源库流程回归。不会在真实 PikPak 账号中删除文件来制造测试故障。
