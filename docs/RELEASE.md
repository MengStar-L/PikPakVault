TelDrive 来源下载改用程序独立管理的 aria2，支持断线续传，并从本地缓存上传 PikPak。

- 首次使用自动下载、校验专用 aria2 1.37.0，不依赖系统安装或外部 RPC。固定发行包与可执行文件 SHA-256，校验失败拒绝运行。
- 专用程序位于 /opt/pikpakvalue/runtime/aria2/，缓存与断点位于 /opt/pikpakvalue/downloads/。不会更改 PikPak 保存目录。
- 下载、速度、校验和上传进度显示在原任务中。下载仅一次，上传读取本地文件；原上传会话继续保留，避免重复创建远端文件。
- 暂停、失败、切号和重启保留断点，上传核验成功后清理缓存；TelDrive 页面提供空间显示与闲置缓存清理。
- 下载前检查空间。子进程停止后才允许清理，真实 aria2 测试覆盖网络断开、暂停续传及主进程被强制终止。
- 18 项浏览器回归测试覆盖桌面、平板、手机及缓存清理确认。
- systemd 与 Docker 为专用程序及缓存提供独立可写目录，升级保留它们。认证不写入 aria2 配置、命令行或下载记录。

从 0.3.1 或更早版本升级：先在新版安装包目录执行 sudo bash deploy/prepare-runtime.sh，为已有 systemd 服务配置两个专用可写目录，再进行正常更新。新版 install.sh、update.sh 自动处理；无需安装系统 aria2。数据库仍为 schema 2，账号、监控与任务保留。

临时缓存占用服务器磁盘。完整备份保留元数据、认证与上传会话；不包含临时文件缓存，迁移后可重新下载。
