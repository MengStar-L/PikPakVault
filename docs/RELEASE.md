v0.2.1 修复手机端备份选择区的排版，以及未初始化实例的备份回滚校验。

独立的 PikPak 个人资源库，保留本地目录与恢复来源。

- 浅色文件资源库：列表 / 网格、多选、搜索、收藏、回收站、完整路径、文件夹动画和可选视频封面。
- 磁链与带提取码分享导入；当前目录内显示传输进度，持久化任务与手动恢复。
- systemd 部署：默认程序目录 `/opt/pikpakvalue`，默认端口 `5675`。
- 设置中检查 GitHub 更新，确认后下载、校验、备份和重启；启动失败或安装中断时恢复旧程序和数据。
- 全数据备份导出 / 导入，包含账号认证、提取码、目录映射、收藏、播放记录、任务和设置；初始化支持导入。

下载对应架构的 tar.gz 与 SHA256SUMS，校验解压后执行 `sudo bash deploy/install.sh`。访问 `http://服务器IP:5675`，初始化代码可从 `journalctl -u pikpak-vault` 获取。

完整备份含数据库和解密密钥，请私密保存。程序保存恢复来源，不保存云端文件内容；来源不可用时无法保证找回文件。
