## 恢复与账户场景

| 场景 | 验证内容 |
| --- | --- |
| 多文件磁链 | 递归登记路径与哈希；恢复同一来源的多个文件只重新转存一个批次 |
| 原账号与新账号 | A 导入、删除、恢复，切换 B 后重建；本地 ID、名称、收藏、播放进度保留 |
| 根目录删除 | 先重建目录，再恢复内容；主动回收站条目不被普通恢复复活 |
| 账号验证与切换 | 不隐式还原已删除根目录；进行中结果归属原账号；旧预览不能确认到新账号 |
| 回收站 | 模拟上游还原后改名、回到账号顶层，程序重新整理到本地期望路径 |
| 分享 | 嵌套来源清单、原分享文件 ID 保留、分页与提取码传递、转存结果明确归属后才能移动 |
| 来源过期 | 显示具体错误并保留记录；替换分享后按旧路径和内容信息恢复 |
| 扫描中断 | 目录错误与第二页请求失败均不提交缺失结论，状态为未知 |
| 冲突 | 同名其他内容不会被覆盖；没有唯一来源匹配时需要处理 |
| 响应丢失 | 离线请求已产生结果但响应丢失，关闭重开 SQLite 后续跑，不重复提交；文件夹使用创建标记核对 |
| 凭据更新 | 旧客户端不能覆盖新凭据或继续旧凭据写请求；令牌续期与身份不匹配检查 |
| 空间 | 单文件选择仍按完整来源批次预估暂存空间，避免仅计算所选文件而低估 |

## 站点与界面

- 初始化代码、管理员登录、Argon2id 密码校验、HttpOnly 会话、CSRF、危险对象操作限制。
- 一致性备份包含 SQLite 与匹配密钥；备份不会让另一服务实例重排正在运行的任务；已有数据库缺少密钥时拒绝创建新密钥。
- 媒体接口按本地资源 ID 鉴权，测试 Range、拒绝任意 URL、HLS 分段绑定账号及过期时间。
- 桌面、平板、手机宽度：1440 / 1024 / 768 / 390 / 360。检查网格、列表、长名称和弹窗溢出。
- 浏览器执行创建、重命名、收藏、移动、详情路径核对、回收站还原；导入后等待实时任务完成、模拟远端删除、扫描、恢复并检查文件状态。
- 1,200 文件目录分页滚动，已渲染文件卡片数量小于 60；搜索能定位最后一页资源。
- 文本中转预览、WAV 实际加载与播放时间推进、完整备份下载、手机设置页与账号弹窗。
- 截图与 HTML 测试报告位于开发工作区的 `artifacts/`，测试数据与入口仅编译进测试二进制，发行程序不能启用。

## 必须继续在实机验证的项目

- **真实资源导入与恢复的双账号流程尚未验证。** 已在当前账号成功执行原顶层专用目录移动到 `My Pack/PikPakVault`，保留根目录 ID，并通过上游查询核对名称和父目录。私有 API 可能变化，仍需要两个可测试账号完成密码/令牌登录、验证挑战、多页带码分享、实际转存 ID、回收站位置、秒传响应及 A → 删除 → A 恢复 → B 重建。
- 浏览器当前用模拟文本与 WAV 验证播放链路；真实视频编码、清晰度切换、长视频 HLS、画中画/全屏、直连 CORS 和过期地址需用实际资源验证。桌面原生 PDF 查看器也受浏览器支持影响。
- Windows 本机无 systemd 或 Docker；systemd 由 Linux CI 和服务器验收。Docker 运行仍需在容器环境验证。
- Windows 本机未运行 race detector；race 和 systemd 进程测试由 Linux CI 执行，最新结果参阅上方 Actions。
- 重启续跑使用数据库关闭重开与持久化状态核对验证，未实施真实机器断电或 Linux 进程强杀验收。

程序备份元数据和恢复来源，不保存文件内容。原始来源失效且云端无可用副本时，保留记录不能保证重新取得内容。

## 2026-09-08 导入降噪与任务结果核验

- 新导入的多文件磁链在最终位置直接登记，测试断言无额外建目录、移动、改名或删除请求；分享忽略目标时只移动顶层结果一次。
- 保留旧暂存检查点；网络响应丢失并重开 SQLite 后按新任务/原来源/目标目录核对，多个同来源新任务不自动认领；拒绝发布者 ID 与转存前已有 ID。
- 卡住或报告错误的上游任务通过实际完整目录两次稳定核验完成；未完成、空目录、目录大小不符、内容变化、分页失败均不登记为完成。
- 每账号请求/写入节流、可取消等待、HTTP 日期格式 Retry-After、账号统一冷却以及验证时暂停后续任务均有回归覆盖。
- 哈希命中直接到最终位置，无暂存目录或多余移动/改名。已取得来源批次后不再对同批次的剩余文件逐个尝试秒传。
- 空目录清理只接受完成任务记录的 ID，非空、改名、仍被引用或分页失败时保留；不扫描前缀后批量删除陌生目录。
- 一次性云端路径校正覆盖新父目录、手动改名/移动、保存来源/收藏/播放位置、只读预览、无云端写入、重复执行无变化，以及分页失败/同名冲突时不部分提交。
- 6 项浏览器测试重新通过，Go vet 通过。测试使用模拟上游，真实任务长期卡住的全部上游变体仍需后续使用验证。

- 当前账号一次性校正实测：读取专用目录 99 项，核对 70 个本地绑定，应用 32 项路径变化，无冲突、无待处理项；本地逐项比较校正报告通过。此过程未发送云端目录/文件写请求。
- 真实清理发现 `GET /drive/v1/files/{id}` 对回收站对象可能返回 HTTP 400 `file_in_recycle_bin`；适配为仅带 ID 的已删除状态，并增加目录/根目录还原后的复核与回归测试。
